# shore1  (HYBRID: opaque FLUX redraw + original soft alpha)
Diagnosis: original is a vertical shoreline strip (128x256) whose alpha is a wide, wavy, feathered ramp on both sides (cov 0.64, ~60% of pixels partial alpha): sea fades out on the left, sand fades out on the right. The old redraw (retry:1) keyed to a hard outline and filled almost the whole frame (cov 0.87), with a dark purple fringe line on the left and hard right edge: soft feather lost. Prompt asked for 'feathered edges' which FLUX cannot express on a green screen.
Method: guide = original colours (premultiplied upscale, bled outward to fill the frame, NO green, guides/shore1_fill.png); prompt asks for a full-frame photographic beach in the same layout (prompts/shore1_a1.txt); then the original alpha is imposed (alpha_tools.hybrid, smooth 1.0). The colour that FLUX paints under the transparent feather is natural beach colour so there is no green/dark fringe.
Result: a1 seed 1 -> diff 0.002, no fringes (checked on dark/light/green).
