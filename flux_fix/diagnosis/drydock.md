# drydock  (HYBRID: FLUX neon redraw on dark backing + original alpha)
Diagnosis: pale rose double-line neon lettering 'DRYDOCK' whose alpha is a soft glow (76% partial alpha, mean 0.38): two thin parallel tubes per letter, open gaps, halo. Old redraw (retry:1) keyed the letters as thick hard-edged strokes with the gap between the two lines filled (cov 0.55 vs 0.38, diff 0.17); the retry prompt asked for open gaps but the green-screen key plus the glow made FLUX fill them.
Method: dark-backing soft guide (guides/drydock_soft_dark.png), prompt 'double outline neon on dark, gaps stay dark' (prompts/drydock_a1.txt), klein_sN_cm.png as colour source, original alpha imposed. Problem found: FLUX's white-hot tube cores plus dark gaps give dark/white rings at partial alpha; fixed with alpha_tools.neon_colors (grow 13 px, hue forced to the glow's median pink keep=0.2): colour is the same pink everywhere the alpha is, so no dark ring on light backgrounds and no white halo.
Result: diff 0.007, a1 seed 1 -> looks like the original, pink, crisp.
UPDATE (user feedback: pixelated): imposing the 8x upscaled 128x32 original alpha showed its source pixels (stair-stepped diagonals). Replaced by alpha_tools.neon_alpha: crisp tube mask from the redraw's own brightness (smoothstep) max soft glow (blurred mask, sigma 9). Still in tolerance (diff 0.068, cov 0.39 vs 0.38). Resubmitted as newest version. Lesson: for small originals (<=128 px) never use the original's alpha as the final alpha when the target is 8x bigger and the shape is sharp-edged; derive alpha from the redraw and only use the original for the tolerance check/low-frequency level.
