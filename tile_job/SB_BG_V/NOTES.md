- Rule positions are identical across tiles because the colour lock keeps line placement, so y seams must sit in the GAP between two rules (find rule rows from the base image) and not on one.
- Check each tile's actual content before writing: my first row-1/2 prompts mentioned a thick rule that is only in row 2 (found by looking at ref thumbnails before the tiles were drawn) -> rewrote before drawing.
- Cut words named per tile: 'BI' / cut stem + 'LL' / 'Boze' + 'AEROPLANE' / B cut + 'OPLANE STORAGE'. All reproduced.
