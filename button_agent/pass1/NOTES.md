# Menu Button Style Definition

This document defines the unified visual style for the game's 4-state lettered capsule menu buttons.
All 59 buttons in the UI share this identical design language, differing only in size and label text.

## Font & Typography
- **Typeface**: Bebas Neue (`fonts/BebasNeue-Regular.ttf`)
- **Characteristics**: Tall, condensed grotesque, uppercase, clean geometric sans-serif.
- **Sizing**: `cap_height = state_height * 0.38` (font size `int(round(85 * (state_h / 160)))`).
- **Placement**: Vertically aligned at `y_top = int(round(state_h * 0.28125))`.
- **Tracking & Spacing**:
  - Inter-letter uniform pitch: `37.5 * (state_h / 160.0)` px.
  - Word space gap: `60.0 * (state_h / 160.0)` px.
  - Text block centered horizontally on the button plate.

## Plate Geometry & Material
- **Silhouette**: Semicircular capsule end caps with radius `(state_h - 2) / 2`.
- **Capsule Frame**: Dark tubular steel rim (outer contour `[15, 15, 14]`, brushed metallic body `[65, 62, 60]`, tubular highlight `[140, 136, 134]`, inner crease `[25, 22, 18]`).
- **Side Brackets & Rivets**: Symmetrical rectangular mounting lugs at middle height (`y = state_h / 2`) with raised, highlighted steel rivets (`r ~ 10px`, center highlight `[185, 180, 175]`).
- **Support Bar**: Thin steel mounting bar underneath the button (`[15, 15, 14]`).
- **Parchment Face**:
  - State 0: Aged silver-grey parchment (`[120, 110, 92]` base).
  - States 1, 2, 3: Warm brass-tan parchment (`[148, 122, 72]` base).
  - Lighting: Cylindrical vertical gradient lit from top-left, highlight at `y ~ 0.25 * state_h`.
  - Texture: Organic parchment mottling generated by fractal noise (`scale=40`, octaves=4, `tile=True`).

## Per-State Lettering Effects
Each button sheet contains 4 stacked states (top to bottom):

1. **State 0 (Normal / Unfocused)**:
   - Plate: Grey parchment with tubular steel frame.
   - Core Lettering: Silver-grey (`#C2C2C2` / `[194, 194, 194]`).
   - Emboss Highlight: Subtle upper-left bevel offset `(-2, -2)` (`#E1E1E1`, 35% opacity).
   - Drop Shadow: Soft dark shadow offset `(+5, +7)` (`[20, 18, 16]`, 95% opacity, blur sigma `3.0`).

2. **State 1 (Hover / Selected)**:
   - Plate: Warm brass-tan parchment.
   - Core Lettering: Pale ivory/cream (`#FEE29D` / `[254, 226, 157]`).
   - Glow: Warm amber glow (`#D7AA5F` / `[215, 170, 95]`, 45% opacity, blur sigma `3.5`).
   - Drop Shadow: Deep warm dark shadow offset `(+5, +7)` (`[10, 8, 5]`, 95% opacity).

3. **State 2 (Active / Clicked)**:
   - Plate: Warm brass-tan parchment.
   - Core Lettering: Radiant orange (`#FFB05C` / `[255, 176, 92]`).
   - Glow: Amber-orange glow (`#DC7828` / `[220, 120, 40]`, 50% opacity, blur sigma `3.5`).
   - Drop Shadow: Dark shadow offset `(+5, +7)` (`[8, 3, 2]`, 95% opacity).

4. **State 3 (Disabled / Highlight)**:
   - Plate: Warm brass-tan parchment.
   - Core Lettering: Fiery crimson/red-orange (`#F9805A` / `[249, 128, 90]`).
   - Glow: Coral glow (`#C8371E` / `[200, 55, 30]`, 50% opacity, blur sigma `3.5`).
   - Drop Shadow: Deep shadow offset `(+5, +7)` (`[5, 2, 2]`, 95% opacity).

## Edge & Seam Quality
- **Alpha**: Clean anti-aliased edge derived from the original capsule vector silhouette with zero keying spill (`rim_hue <= 1.0`).
- **Seam**: Outermost boundary pixels wrap identically (`cand[0] == cand[-1]`, `cand[:, 0] == cand[:, -1] == 0`) ensuring seamless tiling (`seam_cand <= 0.05`).
